# 我的世界：从第一天到下界合金、打龙打凋零

## 第一阶段：活过第一晚（生存模式）
1. 打树拿木头 → 工作台 → 木镐 → 挖石头 → 石镐、石剑、火把
2. 天黑前挖个洞或搭个小屋，放床睡觉（没床就垫高躲着）
3. 吃的：杀猪牛羊、种小麦、烤熟再吃（生吃会中毒的别吃）
4. 记住坐标（F3），家在哪儿要记

## 火柴盒房子（最基础）
- 3×3 到 5×5，石头或木头墙，留门，屋顶封死
- 里面放：床、工作台、箱子、熔炉、火把
- 门口插火把防怪；有条件的挖一圈沟或者垫高

## 装备路线
- 木 → 石 → 铁（挖铁矿烧成铁锭）→ 钻石（Y=-59 附近最多）→ 下界合金
- 下界合金：去下界挖「远古残骸」（Y=8~22 最多）→ 烧成下界合金碎片 → 4 碎片 + 4 金锭 = 下界合金锭 → 锻造台上升级钻石装备
- 附魔台 + 书架，优先保护、耐久、锋利

## 武器怎么用
- 剑：近战，左键砍；横扫之刃能打一片
- 弓：远程，蓄满力伤害高；配箭
- 弩：蓄力后可以存着，多箭附魔一次三发
- 三叉戟：扔出去能捡回来；有「忠诚」附魔会自己飞回；「激流」雨天能冲
- 鞘翅：末地船里拿，穿上后从高处跳下按跳跃键滑翔，配烟花火箭加速

## 打末影龙
1. 找要塞：末影之眼扔出去跟着走
2. 要塞里找末地传送门，12 个末影之眼填满
3. 进末地：先打掉末地水晶（用弓射，或者搭柱子上去砍）
4. 水晶清完再打龙，龙俯冲时砍头；龙息会伤人，躲开
5. 龙死了掉龙蛋和大量经验

## 打凋零
1. 挖 4 个灵魂沙摆成 T 形，上面放 3 个凋零骷髅头（下界要塞打凋零骷髅掉）
2. 召唤后它会爆炸，先躲远
3. 第二阶段会飞，用弓射；最好在下界或者基岩层打，别在自家附近

## 存储与分类
- 箱子：27 格；大箱子两个并排 = 54 格
- 桶：装水/岩浆/牛奶；也能当装饰
- 漏斗：上面吸物品、往下面/侧面送；被红石信号锁住就停
- 分类：漏斗 + 箱子做「过滤」，一格只放一种物品，其它流过去

## 矿车与铁轨（运行逻辑）
- 铁轨：普通轨道，矿车能走
- 动力铁轨：通电后加速/保持速度，红石火把或拉杆供电
- 感应铁轨：矿车经过时发出红石信号（当开关用）
- 矿车：坐人、运东西
- 箱子矿车：能装东西的矿车，配合漏斗装货卸货
- 漏斗矿车：边走边吸地上的物品，也能往箱子里卸
- TNT 矿车：撞到或者被激活会爆炸，别在仓库里用
- 一条线：漏斗矿车在铁轨上跑 → 经过漏斗 → 物品进箱子

## 教她的时候怎么教
- 一次只教一件事，先让她说一遍，再让她做
- 她做错了别凶，问她「你觉得刚才哪一步不对」
- 游戏里的死别当回事，说「死了再来，装备还能再做」
