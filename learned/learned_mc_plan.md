# 我的世界教学计划（妈咪版）

目标：从第一天活下来，到能自己拿下界合金、打末影龙和凋零，会建火柴盒房子，会用剑/弓/弩/三叉戟/鞘翅，会用箱子/桶/漏斗分类，能讲清漏斗矿车/箱子矿车/TNT矿车/铁轨/动力铁轨/感应铁轨的运行逻辑。

## 第一课 活过第一晚
- 打树 → 工作台 → 木镐 → 挖石头 → 石镐石剑火把
- 天黑前挖洞或搭小屋，放床睡觉
- 吃的：打猎、种地，烤熟再吃
- 过关：能说出「第一天先做什么、天黑前要有什么」

## 第二课 火柴盒房子
- 3×3 到 5×5，留门、封顶，室内放床/工作台/箱子/熔炉
- 门口插火把防怪
- 过关：能说出房子最少要有什么、怎么防怪

## 第三课 装备路线
- 木→石→铁→钻石→下界合金
- 铁要烧，钻石在 Y=-59 附近，下界合金要远古残骸+金锭+锻造台
- 过关：能说出下界合金怎么来

## 第四课 武器
- 剑近战、弓蓄力、弩可存箭、三叉戟能扔能捡（忠诚/激流）、鞘翅滑翔+烟花
- 过关：四种武器各说一句用法

## 第五课 存储与分类
- 箱子 27 格、大箱子 54、桶装液体、漏斗吸/送/被红石锁
- 分类：一格一种物品，其它流过去
- 过关：能说出漏斗怎么用、怎么做分类

## 第六课 矿车与铁轨
- 铁轨走车、动力铁轨通电加速、感应铁轨发信号
- 矿车/箱子矿车/漏斗矿车/TNT 矿车各自干什么
- 过关：能讲清「漏斗矿车 + 铁轨 + 漏斗 + 箱子」这条线

## 第七课 下界与下界合金
- 建传送门、挖远古残骸、烧碎片、锻造台升级
- 过关：能说出完整流程

## 第八课 末影龙
- 找要塞、填末影之眼、进末地、先打水晶再打龙
- 过关：能说出顺序和为什么要先打水晶

## 第九课 凋零
- 灵魂沙 T 形 + 三个头颅、召唤后躲爆炸、二阶段会飞
- 过关：能说出召唤材料和打法要点

## 第十课 综合
- 从零到能自己玩：第一天、房子、装备、打龙、存储分类
- 过关：能完整讲一遍自己的路线
